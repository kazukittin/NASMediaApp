# NAS Media

Synology DiskStationに保存したマンガ、写真、ビデオ、音声作品を、1つのAndroidアプリから閲覧・再生するための個人向けアプリです。

## 主な機能

- SMB経由でNASへ接続
- ZIP形式のマンガ閲覧
  - 左開き
  - タップ・スワイプによるページ移動
  - 読書位置の保存
  - ページ一覧からのジャンプ
- 写真フォルダのサムネイル表示と全画面閲覧
- NAS上のビデオをストリーミング再生
- 音声作品の連続・バックグラウンド再生
  - Android標準メディアコントロール対応
  - 通知・ロック画面から操作可能
- ファイル名やフォルダ名のRJコードを認識
  - DLsiteの公開作品情報とジャケットを表示
  - サークル、声優、ジャンル、発売年による絞り込み
- NASのログイン情報をAndroid Keystoreで暗号化して保存

## 動作環境

- Android 8.0（API 26）以上
- SMBが有効なNAS
- NASとAndroid端末が接続されたローカルネットワーク

開発時はSynology DiskStation DS223jとSMB3で動作確認しています。

## セットアップ

1. NASにアプリ専用ユーザーを作成します。
2. マンガ、写真、ビデオ、音声の共有フォルダへ必要最小限の読み取り権限を付与します。
3. Android Studioでこのプロジェクトを開きます。
4. Android端末を接続してアプリを実行します。
5. NASのIPアドレス、ユーザー名、パスワードを入力します。

想定している共有フォルダ名は次のとおりです。

| 種類 | 共有フォルダ |
| --- | --- |
| マンガ | `Manga` |
| 写真 | `Picture` |
| ビデオ | `video` |
| 音声 | `Voice` |

## セキュリティ

- インターネットへSMBを公開せず、信頼できる自宅LAN内で利用してください。
- NASには管理者アカウントではなく、読み取り専用のアプリ専用ユーザーを推奨します。
- 保存したNASパスワードはAndroid Keystoreの鍵を使って暗号化されます。
- 認証情報はバックアップと端末移行の対象外です。
- `local.properties`やビルド生成物はGitの管理対象外です。

## DLsite作品情報について

RJコードが含まれるファイル名・フォルダ名では、DLsiteの公開ページから作品情報を取得します。サイト側の仕様変更や作品の公開状況によって、情報を取得できなくなる可能性があります。取得できない場合もNAS上のファイル閲覧・再生は継続できます。

DLsiteおよび各作品の名称・画像・情報に関する権利は、それぞれの権利者に帰属します。
